## About the project
This website was built  to present my projects, skills and current experiments and to show my interests in web development, JavaScript, electronics and robotics

The project includes:
- responsive layout for desktop and mobile,
- about, projects, skills and contact sections,
- animated elements revealed while scrolling,
- a dark mode / light mode switch with saved preferences,
- a randomly appearing duck,
- background images of duck.

 Used languages  and fonts
- HTML5
- CSS3
- JavaScript
- The Magic Cookie.ttf (FONT)
