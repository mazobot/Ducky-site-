# Web OS 
A browser-based operating system interface created as a personal web development project.

##About
Web OS is an interactive desktop environment that runs directly in a web browser.
The project is designed to look and feel like a simple operating system while being built entirely with web technologies.
It includes a desktop, applications, interactive windows and custom UI elements.

##Features
-Browser-based desktop environment
-Interactive windows
-Applications
-Built-in calculator
-Interactive desktop elements
-Dark/light theme
-Responsive design
-Custom UI
-Interactive Among Us themed elements
-Runs directly in the browser
-No installation required

##Technologies
The project was created using:
- HTML5
- CSS3
- JavaScript
